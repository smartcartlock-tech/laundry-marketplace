# מכבסה בקליק — פלטפורמת מרקטפלייס רב-מכבסתית

מערכת אמיתית (לא דמו): Backend API + PWA לפי איפיון v1.1, multi-tenant מהיום הראשון.

## מה כאן
- **מרקטפלייס ללקוחות**: חיפוש מכבסות, דף מכבסה עם מחירון חי, סל והזמנה, מעקב סטטוס חי, ביקורות.
- **אימות**: OTP (וואטסאפ דרך Twilio, או קוד דמו מוצג כש-DEMO_OTP=true), Google Sign-In (דורש GOOGLE_CLIENT_ID).
- **לוח ניהול מכבסה**: תור הזמנות חי וסטטוסים, מחירון, חלונות איסוף/החזרה, לקוחות, דוחות, שיבוץ שליחים.
- **אפליקציית שליח**: הצעות שיבוץ (אישור/דחייה), מסלול פעיל, סימון נאסף/הוחזר, ניווט ל-Waze.
- **מועדון נקודות**: צבירה אוטומטית במסירה, מימוש כהנחה בעגלה, יתרות לפי מכבסה.
- **אדמין פלטפורמה**: אישור מכבסות ושליחים, רישום שליחים (3 מודלים: פרטי/משותף/פלטפורמה), תמונת מצב.
- **Onboarding AI**: העלאת תמונות מחירון/שעות/תקנון → Gemini מחלץ פרופיל → מסך סקירה → יצירה (ממתין לאישור אדמין).
- **API לבוט וואטסאפ (CleanShop)**: `/api/bot/*` עם X-Api-Key לכל מכבסה — אותן הזמנות, סטטוסים ומועדון.
- **תשלומים**: מזומן לשליח או "תשלום מקוון (דמו)" — ללא סליקה אמיתית בשלב זה.
- **מעקב הזמנה ציבורי**: קישור `#/track/<קוד>` ללא התחברות — ציר סטטוס מלא ללקוח.
- **מסמכים חשבונאיים (דמו)**: חשבונית עסקה/קבלה/מרכזת בהתאם לסוג העוסק (מורשה/פטור), הפקה אוטומטית במסירה, דוח התחשבנות ובדיקת עקביות.
- **מצב כהה לבדיקה**: כפתור 🌙/☀️ צף (היפוך גלובלי), נשמר מקומית.

## הרצה
```
cp .env.example .env   # מלאו DATABASE_URL ו-JWT_SECRET
npm install
SEED_DEMO=true npm start   # מגרית, מזריע דמו אם ריק, ומאזין
```

## משתמשי דמו (SEED_DEMO)
| תפקיד | טלפון |
|---|---|
| מנהל פלטפורמה | +972500000001 |
| לקוחה | +972500000002 |
| בעל מכבסה (האחוזה) | +972500000003 |
| שליח מכבסה | +972500000004 |
| שליח פלטפורמה | +972500000005 |

כש-DEMO_OTP=true הקוד מוצג על המסך (ברירת מחדל: פעיל — נועד לסביבת הדמו בלבד; בפרודקשן אמיתי יש להגדיר DEMO_OTP=false כדי שהקוד יישלח רק בוואטסאפ ולא יוצג). הודעות סטטוס נשלחות בוואטסאפ אם Twilio מוגדר (סנדבוקס: רק למספרים שהצטרפו).

### ספק OTP (A4)
שליחת קוד הכניסה עוברת דרך ממשק מוחלף `sendCode` (src/otp-provider.js). הבחירה נשלטת ב-OTP_PROVIDER:
- `auto` (ברירת מחדל): וואטסאפ דרך גשר הבוט (BOT_OUTBOUND_URL/BOT_OUTBOUND_KEY) או Twilio אם מוגדרים; אחרת נפילה לקוד דמו מוצג — במצב demo בלבד.
- `whatsapp` / `bot`: כופה שליחה אמיתית; כשל = 503 (אין נפילה שקטה לדמו).
- `demo`: עוקף שליחה — חוקי רק ב-APP_MODE=demo. ב-pilot נחסם כדי שלא יוצג קוד על המסך.
בפיילוט ללא עלות: מגדירים BOT_OUTBOUND_URL/BOT_OUTBOUND_KEY (הקוד יוצא מהבוט הקיים), או משתמשים בכניסת Google (GOOGLE_CLIENT_ID).

## API לבוט CleanShop
- `GET /api/bot/pricelist`, `GET /api/bot/windows`
- `POST /api/bot/orders` {phone, name?, items:[{item_id, qty}], address, pickup_at?, notes?}
- `GET /api/bot/orders/:id`, `GET /api/bot/customers/:phone/latest-order`
- אימות: header `X-Api-Key` (לכל מכבסה מפתח משלה, נוצר אוטומטית בטבלת tenants).

## ארכיטקטורה
Express + PostgreSQL (pg, ללא ORM). כל הישויות נושאות tenant_id. סטטוסים: new → confirmed → picked_up → in_work → ready → out_for_delivery → delivered (+cancelled). נקודות נזקפות רק בסטטוס delivered. JWT stateless. PWA סטטי מוגש מאותו שירות.

## פריסה (Render)
ראו render.yaml. ה-DB בפרוד הוא Neon free Postgres נפרד (eu-central-1, ללא PGSCHEMA). SEED_DEMO ו-DEMO_OTP פעילים בסביבת הדמו בלבד — כיבוי שניהם הוא go-live gate (ראו docs/GO-LIVE.md כשייווצר).
