# GO-LIVE — צ'קליסט מוכנות (אפיק H)

מסמך הכנה בלבד — **לא מבצעים go-live בפועל**. הסימון האחרון (הזזת שער APP_MODE) בתיאום היזם בלבד.

## 1. משתני סביבה (Render)
- [ ] `APP_MODE=pilot`
- [ ] `DEMO_OTP=false` — OTP אמיתי דרך Twilio בלבד
- [ ] `SEED_DEMO=false` — אין נתוני דמו חדשים
- [ ] `ADMIN_PHONE=+972XXXXXXXXX` — מספר היזם (בוטסטרפ אדמין ראשון, ראו סעיף 3)
- [ ] `VAPID_SUBJECT=mailto:<כתובת אמיתית>` — לא example.com
- [ ] `PUBLIC_URL` / `APP_BASE_URL` מצביעים לדומיין הסופי (אם נרכש — כרגע אין דומיין)
- [ ] `GOOGLE_CLIENT_ID` — OAuth client לדומיין הסופי (Google Cloud Console)
- [ ] `SENTRY_DSN` — מומלץ לפני go-live (B3)
- [ ] `PILOT_LAUNDRY_NAME` — שם מכבסת הדגל

## 2. אבטחה ותוכן (חסימות)
- [ ] פרטיות/תנאים אושרו לפרסום (C1)
- [ ] Twilio: מעבר מסנדבוקס למספר אמיתי מאומת
- [ ] רשימת שולחי ביקורות התקבלה מהשותף הראשון (B2 — אין שליחת ספאם!)
- [ ] מדיניות דמי שירות עוגנה בהסכם עם המכבסות

## 3. נתונים
- [ ] גיבוי מלא לפני כל שינוי: `node scripts/backup.js` (מאומת לפי E1)
- [ ] ניקוי נתוני דמו: `CONFIRM_PURGE_DEMO=yes node scripts/purge-demo.js` — מסיר 4 מכבסות דמו ומשתמשי +9725000000xx
- [ ] אדמין ראשון: הדיפלוי עם `ADMIN_PHONE` יוצר אדמין אוטומטית ב-boot (בלי SEED_DEMO). כניסה ראשונה דרך OTP אמיתי.
- [ ] מכבסת הדגל נרשמת דרך זרימת ההצטרפות האמיתית (A1) — לא דרך זריעה

## 4. תשתית

- [ ] קריאת דפים: נחיתה, פרטיות, תנאים — מובייל ודסקטופ
